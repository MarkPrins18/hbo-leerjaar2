# KMP-opzet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Het API-contract van de server verhuist naar een nieuwe KMP-module `shared`, en er komt een lege Compose Multiplatform-app (alleen Android) naast de server.

**Architecture:** Vier Amper-modules: `shared` (kmp/lib, jvm + android, alleen `@Serializable` contractklassen), `server` (jvm/app, hangt af van `shared`), `composeApp` (kmp/lib met Compose, alleen android, de UI) en `androidApp` (android/app, alleen `MainActivity`). Het contract verhuist ongewijzigd naar packages onder `shared.`; de server krijgt nieuwe imports.

**Tech Stack:** Kotlin 2.4.0, Amper via `kotlin`/`kotlin.bat` (Kotlin Toolchain 0.12.0), Ktor 3.5.2, kotlinx-serialization, kotlinx-datetime, Compose Multiplatform, Android SDK.

**Spec:** `docs/superpowers/specs/2026-11-10-kmp-opzet-design.md`

## Global Constraints

- Geen Gradle. Bouwen en testen met `.\kotlin.bat build` / `.\kotlin.bat test` (Linux/CI: `./kotlin ...`).
- Iedereen installeert de Android SDK; er komt geen server-only build. De build-regel in `.claude/claude.md` blijft gelijk.
- Modellen, DTO's en responses veranderen alleen van plek en package, niet van inhoud (`@SerialName`, velden, defaults, volgorde blijven gelijk).
- `shared` bevat alleen `@Serializable` contractklassen en hun enums: geen logica, geen `java.*`, geen Ktor, geen Exposed, geen server-only velden.
- Server-regels uit `.claude/claude.md` blijven gelden; `Route → Service → Repository` verandert niet.
- `applicationId` en namespace: `nl.carsharing.app`; `minSdk` 26. Kotlin-packages in `composeApp` en `androidApp`: `nl.carsharing.app`.
- Alle versies in `libs.versions.toml`. kotlinx-datetime krijgt dezelfde versie die Exposed 1.3.1 al binnenhaalt.
- Tests: `.claude/testing.md` (in `server/test/`, zonder package, `kotlin.test`, Nederlandse testnamen in backticks).
- Werk op branch `kmp-opzet`. Commit alleen de bestanden van de taak (de werkmap bevat ongerelateerde wijzigingen, o.a. `.claude/skills/`).

## Review Focus

1. **JSON-vorm van `Car`:** na de verhuizing blijft de discriminator `"type": "ICECar"` / `"BEVCar"` / `"FCEVCar"`. Een andere waarde breekt elke client. Test in Task 1.
2. **Datum- en tijdformaat:** `Instant` blijft een ISO-string, `LocalTime` blijft `"HH:mm"`. Test in Task 1.
3. **Geen wachtwoordhash naar de app:** `UserResponse` bevat alleen `id` en `email`, en `User` staat niet in `shared`. Test in Task 1, grep-check in Task 2.
4. **Enums zonder `@Serializable` (`RideStatus`):** blijven als naam geserialiseerd (`"IN_PROGRESS"`). Test in Task 1.
5. **Schone checkout op CI:** alle vier modules bouwen op `ubuntu-latest`, niet alleen de server. Check in Task 4.

### Task 1: Contracttest vóór de verhuizing

Legt de huidige JSON-vorm vast, zodat Task 2 aantoonbaar niets verandert. De test slaagt nu al; hij is een vangnet, geen rode test.

**Files:**
- Create: `server/test/ContractSerializationTest.kt`

**Interfaces:**
- Produces: testclass `ContractSerializationTest`. Task 2 past alleen de imports aan.

- [ ] **Step 1: Schrijf de test**

Gebruik `Json` met standaardinstellingen (zoals Ktor's `json()` in `Serialization.kt`) en lees resultaten terug als `JsonObject`. Blokindeling volgens `testing.md` (`// ==================== Test data ====================`, `// ==================== 1. Serialisatie: contract ====================`).

| Test | Assertions |
|---|---|
| `` `ICECar heeft type ICECar in de JSON` `` | `Json.encodeToString<Car>(iceCar)` → `obj["type"]` = `"ICECar"`; terug decoderen als `Car` geeft `iceCar` |
| `` `BEVCar en FCEVCar hebben hun eigen type` `` | `"BEVCar"` en `"FCEVCar"`; round-trip gelijk |
| `` `Reservation zet Instant als ISO-string en status als naam` `` | `startTime = Instant.parse("2026-01-01T10:00:00Z")` → `obj["startTime"]` = `"2026-01-01T10:00:00Z"`; `obj["status"]` = `"PENDING"` |
| `` `Ride zet RideStatus als naam` `` | `obj["status"]` = `"IN_PROGRESS"` |
| `` `RentalTerms zet LocalTime als uur en minuten` `` | `pickupTimeStart = LocalTime(9, 0)` → `obj["pickupTimeStart"]` = `"09:00"` |
| `` `UserResponse bevat alleen id en email` `` | `User(1, "a@b.nl", "hash").toResponse()` → `obj.keys` = `setOf("id", "email")` |
| `` `CarChangeDto leest enums uit de JSON` `` | `Json.decodeFromString<CarChangeDto>("""{"fuelType":"DIESEL","vehicleType":"PASSENGER_CAR"}""")` → velden `FuelType.DIESEL`, `VehicleType.PASSENGER_CAR` |

- [ ] **Step 2: Draai de tests**

Run: `.\kotlin.bat test`
Expected: alle tests PASS, inclusief de 7 nieuwe.

- [ ] **Step 3: Commit**

```bash
git add server/test/ContractSerializationTest.kt
git commit -m "test: leg JSON-vorm van het API-contract vast"
```

### Task 2: Module `shared` en verhuizing van het contract

**Files:**
- Create: `shared/module.yaml`
- Create (via `git mv`, package aangepast): `shared/src/models/{Car,Photo,RentalTerms,Reservation,Ride}.kt`, `shared/src/dto/{CarDto,RentalTermsRequest,RideFinishRequest}.kt`, `shared/src/requests/{LoginRequest,RegisterRequest,ReservationRequest}.kt`, `shared/src/responses/{FuelCostResponse,LoginResponse,TcoResponse,UserResponse}.kt`
- Create: `server/src/dto/CarFilter.kt`, `server/src/models/ReservationStatuses.kt`, `server/src/mappers/UserResponseMapper.kt`
- Modify: `project.yaml`, `server/module.yaml`, `libs.versions.toml`, alle bestanden in `server/src` en `server/test` die verhuisde klassen gebruiken (~80)

**Interfaces:**
- Consumes: `ContractSerializationTest` uit Task 1.
- Produces: packages `shared.models`, `shared.dto`, `shared.requests`, `shared.responses` met dezelfde klassen als nu. Blijft in de server: `models.User`, `models.Location`, `models.ACTIVE_RESERVATION_STATUSES`, `dto.CarFilter`, `mappers.toResponse(User): UserResponse` (extensie `fun User.toResponse()`), `models.rdw.*`, `models.gemini.*`.

- [ ] **Step 1: Module aanmaken**

- `libs.versions.toml`: `kotlinx-datetime` toevoegen. Zoek de versie op die Exposed 1.3.1 binnenhaalt (via de dependency-uitvoer van Amper of de POM van `exposed-kotlin-datetime`) en gebruik precies die.
- `shared/module.yaml`: `product: { type: kmp/lib, platforms: [jvm, android] }`, dependency `$libs.kotlinx.datetime: exported`, `settings: kotlin: serialization: enabled`, `android: namespace: nl.carsharing.shared`.
- `project.yaml`: `shared` toevoegen.
- `server/module.yaml`: dependency `../shared`.

- [ ] **Step 2: Bestanden verplaatsen** met `git mv` naar de paden hierboven (`server/src/dto/LoginRequest.kt` e.a. gaan naar `shared/src/requests/`). Zet in elk bestand het package op `shared.<oud package>`.

- [ ] **Step 3: Server-only delen terugzetten**
- `CarFilter` uit `CarDto.kt` naar `server/src/dto/CarFilter.kt` (package `dto`).
- `ACTIVE_RESERVATION_STATUSES` uit `Reservation.kt` naar `server/src/models/ReservationStatuses.kt` (package `models`, met `import shared.models.ReservationStatus`). Bestaande imports `models.ACTIVE_RESERVATION_STATUSES` blijven werken.
- `fun User.toResponse()` uit `UserResponse.kt` naar `server/src/mappers/UserResponseMapper.kt` (package `mappers`).

- [ ] **Step 4: Imports herschrijven** (zoek-en-vervang over `server/src` en `server/test`)
- `import requests.` → `import shared.requests.`
- `import responses.toResponse` → `import mappers.toResponse`; overige `import responses.` → `import shared.responses.`
- `import models.<X>` en `import dto.<X>` voor verhuisde klassen → `import shared.models.<X>` / `import shared.dto.<X>`.
- Waar `import models.*` of `import dto.*` staat: `import shared.models.*` / `import shared.dto.*` ernaast zetten; de oude wildcard alleen weghalen als het bestand niets uit de server-packages meer gebruikt.
- In verhuisde bestanden: imports onderling ook naar `shared.` (bijv. `CarDto.kt` → `shared.models.FuelType`).

- [ ] **Step 5: Bouwen en testen**

Run: `.\kotlin.bat build` en daarna `.\kotlin.bat test`
Expected: build slaagt; alle tests PASS, inclusief `ContractSerializationTest`.

- [ ] **Step 6: Grenzen controleren**

Expected: geen uitvoer.

Run: `git grep -nE "^package (models|dto|requests|responses)$" -- shared`
